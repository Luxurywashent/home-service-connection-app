# HSC Web / Mobile Feature Matrix

Audit date: 2026-10-17. Each row was classified from source, not from a live two-app walkthrough.

Status meanings:

- **Fully connected** — both apps use the same JobSync identity or service, and no mapping defect was found on that path.
- **Partially connected** — a shared API or table exists, but the filter, formula, role, date, or client differs.
- **Disconnected** — the apps do not read and write the same record, or one screen invents a number the other does not use.
- **Not verified** — the server route or page exists, and this audit did not trace the screen, permissions, and failure path end to end.

Verification for every row is **code trace only** unless the cell says otherwise. Production data was not queried.
